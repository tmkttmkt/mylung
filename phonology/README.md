# 読み方

この言語の文字には、唯一の正式な音価を定めない。文字列が言語の本体であり、読み方は、文章を音声化するための交換可能なプロファイルとして扱う。

ここでは最初の例として「基本読み」を定義する。これは標準発音や正しい発音ではなく、他の読み方より優先されない。

## 基本読み

### 母音字

| 文字 | IPA | 日本語での目安 |
|---|---|---|
| `1` | /a/ | ア |
| `2` | /i/ | イ |
| `3` | /u/ | ウ |
| `5` | /o/ | オ |

`e` に相当する母音は使用しない。

### ゼロ初声字

| 文字 | 音価 | 働き |
|---|---|---|
| `4` | 無音 | 前後の母音を別の音節に分ける |

```text
15   /ao/    1音節
145  /a.o/   2音節
14142 /a.a.i/ 3音節
```

### 子音字

| 文字 | IPA | 日本語での目安 |
|---|---|---|
| `6` | /k/ | カ行の子音 |
| `7` | /g/ | ガ行の子音 |
| `8` | /r/ | ラ行に近い音 |
| `9` | /p/ | パ行の子音 |
| `A` | /s/ | サ行の子音 |
| `B` | /t/ | タ行の子音 |
| `C` | /n/ | ナ行の子音 |
| `D` | /m/ | マ行の子音 |
| `E` | /l/ | 英語の *l* に近い音 |
| `F` | /h/ | ハ行の子音 |

`8` と `E` は、この基本読みでは /r/ と /l/ を区別する。日本語話者が両者を同じラ行音で読んでも、別の読み方として許容される。

## 読み上げ規則

- 原則として一文字に一つの音を対応させる。
- 母音字の連続は、`4` がなければ同じ音節で読む。
- 同じ母音字の連続は長母音として読んでもよい。
- 子音連続には母音を補わず、そのまま読む。
- 語末の子音にも母音を補わない。
- 強勢は固定しない。必要なら各読み方の話者が自然な位置に置く。
- 発音しにくい場合の母音挿入や音の変化は許容するが、それによって綴りは変化しない。

日本語風に読む場合の補助母音は、語の構成要素ではない。例えば語末の `6` /k/ を「ク」と読んでも、末尾に母音字 `3` があるとは解釈しない。

## 境界と句読点

`0` 自体は発音せず、連続数に応じた間またはイントネーションで表す。

| 表記 | 読み方の目安 |
|---|---|
| `0` | 単語境界。短く区切る |
| `00` | 読点。短い間を置く |
| `000` | 句点。文末の抑揚と長めの間を置く |

## 別の読み方

別の読み方は、この表と同じ文字体系および音節境界の規則を尊重する限り、自由に作成できる。方言、個人差、朗読用の音価、音声合成用の音価は、いずれも対等な読み方として扱う。

読み方を区別する必要がある場合は、「基本読み」「日本語読み」のようにプロファイル名を明示する。「正しい発音」「正式発音」という分類は設けない。
