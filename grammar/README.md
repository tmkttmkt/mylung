## 文法資料の表記

文法資料では、未定の単語を説明するために日本語の仮訳を使用します。

```text
読む 私 本
```

これはVSO（動詞・主語・目的語）という語順を示す説明用の表記であり、`読む`、`私`、`本` が実際の単語として決まっているわけではありません。

実際の言語では単語を `1`〜`F` で書き、単語間を `0` で区切ります。`00` は読点、`000` は句点です。文法資料では読みやすいように、`0` の代わりに空白を置き、`00` と `000` を `、` と `。` に置き換えた表記も使用します。

```text
実表記：     A310B205C4
分かち書き： A31 B2 5C4
```

資料中の記号は次の意味で使用します。

| 表記 | 意味 |
|---|---|
| `V` | 動詞・述語 |
| `S` | 主語 |
| `O` | 目的語 |
| `・主` | 説明用の主語助詞（実際の単語は未定） |
| `・対` | 説明用の目的語助詞（実際の単語は未定） |
| `(要素)` | 省略できる要素 |
| `要素*` | 0回以上繰り返せる要素 |

`・`、丸括弧、`*`、空白、日本語の仮訳は説明用であり、実際に使用できる文字には含まれません。
