# 語形成

接頭辞、接尾辞、活用、派生語、複合語の規則を管理します。

単語は可変長とし、先頭文字だけで品詞を決定する方式にはしません。

## 意味核と品詞標識

一般的な内容語は、意味の中心となる `核` と、語の使い方を示す `品詞標識` から作ります。核は必ず母音字で終わります。

```text
核                  → 概念・抽象
派生語              = 核 + 品詞標識
```

最初に用意する品詞標識は次の三つです。

| 標識 | 形 | 働き |
|---|---|---|
| 名詞標識 | `6` | 一般的・具体的な名詞を作る |
| 動詞標識 | `8` | 動詞を作る |
| 形容詞標識 | `A` | 名詞または動詞を形容する形容詞を作る |

標識は子音字1文字で、核と同じ単語の語末に必ず付けます。核と標識の間に単語区切りの `0` は置きません。

標識は語頭の文字分類ではなく、意味を持つ派生要素として扱います。代名詞、助詞、助動詞などの機能語には、この規則を適用しない場合があります。

## 品詞の変更

意味核を残し、品詞標識を付け替えることで関連語を作ります。

```text
生命核                → 生命という概念
生命核 + `6` → 生き物、具体的な生命体
生命核 + `8` → 生きる
生命核 + `A` → 生きている、生命のある
```

```text
言語活動核                → 言語活動という概念
言語活動核 + `6` → 具体的な発話、言語表現
言語活動核 + `8` → 話す
言語活動核 + `A` → 言語的な、発話された
```

品詞標識を外した核は、概念・抽象を表す語として単独で使用できます。派生語として使用する場合は、対応する品詞標識を省略できません。

## 意味の予測可能性

品詞標識を付け替えた語の意味は、核からある程度推測できます。ただし、すべての組み合わせを使用する必要はなく、実際の語義は辞書に記録します。

例えば、名詞形が具体物、物質、出来事、実例のどれを表すかは、意味核と慣用によって決まります。派生規則は品詞を決めますが、語義の細部まで機械的に決定しません。

## 複合語

複合語では、複数の意味核を組み合わせ、全体の最後に品詞標識を付けます。

```text
言語活動核 + 生命核 + `6` → 人間
```

これは「話す＋生き物」に相当します。各構成語の品詞標識まで連結するのではなく、意味核を直接組み合わせます。

```text
話す       = 言語活動核 + `8`
生き物     = 生命核 + `6`
人間       = 言語活動核 + 生命核 + `6`
```

複合語は、前置する修飾核と、その後ろに置く中心核から作ります。

```text
修飾核 + 中心核 + 全体標識
```

前の核が、後ろの中心核の種類、性質、材料、用途、起源などを限定します。複合語全体は中心核の一種です。

```text
言語活動核 + 生命核 + `6` → 人間
水核 + 場所核 + `6`       → 水に関係する場所
```

後置核による別の結合方式は現時点では作りません。前置方式だけで不足することが分かった場合に再検討します。

## 形容詞の扱い

形容詞形は、名詞と動詞の両方を形容できます。どちらを形容しても、この言語では同じく `形容詞` と呼びます。

名詞を形容する場合：

```text
大きさの核 + `A` + 物
```

「大きい物」

動詞を形容する場合：

```text
速さの核 + `A` + 動く
```

「速く動く」

日本語訳では「速く」が副詞に見えますが、この言語では名詞を形容する形と同じ形容詞です。副詞という別の品詞や、副詞標識は作りません。

性質を文として述べる場合は、既存の方針どおり同定動詞を使用します。

```text
同定する 物 大きさの核 + `A`
```

「物は大きい」

形容詞は、名詞や動詞だけでなく、別の形容詞も形容できます。これにより、複数の性質を単に並べるだけでなく、一方の形容詞がもう一方の程度・様態・評価を限定する形容詞句を作れます。

```text
人間 大きいA 良いA
```

形容詞は被形容語の後ろに置く方式を仮採用します。形容詞列の並列と階層は、弱い境界 `00` の位置で区別します。

```text
N0A100A2 → A1とA2がそれぞれNを形容する
N00A10A2 → A2がA1を形容し、形容詞句全体がNを形容する
```

```text
人間0大きいA00良いA → 大きくて、良い人間
人間00大きいA0良いA → 良い形で大きい人間
```

これは暫定規則です。実際の例文で扱いにくい構造が見つかった場合は、`00` の作用範囲と形容詞列の結合方向を再検討します。

## 名詞の数

名詞は、単数と複数を形の上で区別しません。`核 + 6` は一個にも複数にも使用でき、実際の数は文脈から判断します。

数を明示する必要がある場合は、名詞そのものを変化させず、数量語を付けます。`5` を使った「すべて」や、集団を表す専用形式の詳しい作り方は未決定です。

この規則は一般名詞についてのものです。代名詞と固有名詞が単数を基本とするか、数について中立になるかは別に決定します。

## 予約標識

次の文字は将来使う標識として予約し、現時点では通常の語形成に使用しません。

| 標識 | 予定する働き | 状態 |
|---|---|---|
| `7` | 固有名詞標識 | 予約。詳しい用法は未決定 |
| `9` | 節名詞化標識 | 予約。節への付け方は未決定 |

`7` は名前を他の一般名詞から区別するために使用する予定です。`9` は複数の単語からなる節全体を、出来事・内容・事実として名詞の位置に置くために使用する予定です。
