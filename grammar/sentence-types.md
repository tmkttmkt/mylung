# 文の種類と助動詞

文の種類、時制、相、否定、法、話者の判断、情報源は、動詞の直後に置く助動詞で表します。

一部の助動詞は語形が確定しています。未確定の助動詞の日本語名は説明用の仮称です。表記方法については [文法資料の表記](README.md#文法資料の表記) を参照してください。

現在確定している助動詞の一覧と対応する概念核は [助動詞](../words/auxiliaries.md) を参照してください。

## 基本形

助動詞を含む述語全体を文頭に置き、その後に主語と目的語を置きます。

```text
動詞 助動詞* 主語 目的語
```

助動詞は必要なものだけを使用します。通常の肯定文には、文が断定文であることだけを示す専用助動詞を必要としません。

## 助動詞境界の非正式な省略

正式表記では、動詞と助動詞の間、および助動詞同士の間に単語区切り `0` を置きます。非正式な表記では、この位置の `0` だけを省略できます。

```text
D1F280E30D2 → 正式表記：話す0否定0命令
D1F28E3D2   → 非正式表記：話す＋否定＋命令
```

省略しても、助動詞は品詞上独立した機能語として扱います。名詞・代名詞・助詞などとの境界にある `0` は省略できません。

```text
D1F2801 → 話す0私：正しい
D1F281  → 不成立または別の一語として解釈する
```

## 助動詞の順序

複数の助動詞を使う場合は、基本的に次の順序で並べます。

```text
動詞 → 相 → 時制 → 否定 → 法 → 文の用途 → 情報源・認識態度
```

この順序は暫定であり、例文を作りながら調整します。

## 時制

| 仮称 | 意味 |
|---|---|
| 無標 | 時制と一時性を指定しない |
| `現況` | 発話時点で一時的に成立している |
| `過去` | 発話時点より前に成立した |
| `未来` | 発話時点より後に成立する |

`現況` は一般的な現在時制ではなく、その状態が一時的であることを明示します。

```text
住む 現況 私 東京
```

「私は現在、一時的に東京に住んでいる」

```text
住む 私 東京
```

時期や一時性を明示しない「私は東京に住む／住んでいる」

## 相

最初に次の二つを用意します。

| 仮称 | 意味 |
|---|---|
| `進行` | 動作が進行中である |
| `完了` | 動作が完了している |

```text
読む 進行 私 本
読む 完了 過去 私 本
```

## 否定

否定助動詞は `E3` です。否定する述語または形容詞の直後に置き、その作用域を否定します。意味概念としての否定・不成立には独立核 `E35` があります。

```text
読む E3 私 本
```

「私は本を読まない」

禁止専用の助動詞は作らず、`E3` 否定と `D2` 命令を組み合わせます。

```text
読む E3 D2 あなた 本
```

「本を読むな」

決定済みの語だけを使った例：

```text
D1F280E301000
```

「私は話さない。」

```text
B1B280E3010810D1F2D185E56072000
```

「私は人間ではない。」

## 法

| 語形・仮称 | 意味 | 対応する概念核 |
|---|---|---|
| `D3` 可能 | 主体または状況により命題を実現できる | `B262D5` 能力 |
| `E2` 願望 | 命題の成立を望む | `E2B5` 希望・欲求 |
| `D5` 意思 | 主体が命題を成立させようとする | `B2E1D1` 意思 |
| `推量` | 話者が命題の成立を推測する | 未定 |

`推量` と後述する `不確定` の違いは、例文を作りながら検討します。

### 願望

願望助動詞 `E2` は、主語または文脈上の主体が命題の成立を望むことを表します。

```text
読む E2 1 本
持つ E2 1 本
```

「私は本を読みたい」「私は本を持ちたい／本が欲しい」

希望・欲求は助動詞だけの文法概念ではなく、独立核 `E2B5` を持ちます。

```text
E2B58 1 C1D5
```

「私は戦争を求める。」

この `E2B58` は希望・欲求核から作った内容動詞で、助動詞 `E2` とは別の語です。

### 意思

意思助動詞 `D5` は、主体が命題を成立させようとすることを表します。単に成立を望む `E2` とは区別します。

```text
話す D5 1
```

「私は話すつもりだ／話そうとする。」

### 能力・可能

可能助動詞 `D3` は、主体の能力または状況により命題を成立させられることを表します。

```text
話す D3 1
```

「私は話せる。」

## 文の用途

| 語形 | 意味 | 対応する概念核 |
|---|---|---|
| `F3` | 疑問。命題を問いとして提示する | `F3B1` 疑問・問い |
| `D2` | 命令。聞き手に命題の成立を命令として要求する | - |
| `F2` | 依頼。話者が聞き手に命題の成立を求める | `F2D5` 依頼・要請 |

### 疑問

疑問 `F3` は、相手に真偽や不足情報を問う文用途です。話者の確信不足を示す `不確定` などの認識態度とは別に扱います。

```text
読む F3 あなた 本
```

「あなたは本を読むか？」

### 命令

命令では、聞き手である主語を文脈から省略できます。

```text
D1F280D2000
```

「話せ。」

否定 `E3` を命令 `D2` の前に置くと禁止になります。

```text
D1F280E30D2000
```

「話すな。」

### 依頼

依頼 `F2` は、話者が聞き手に命題 `P` の成立を求める文用途です。命題の主語を聞き手に固定しません。

```text
読む F2 2 本
```

「あなたが本を読むよう依頼する／本を読んでください。」

```text
行く F2 1
```

「私が行くという事態の成立を聞き手に求める。」

後者は文脈によって「私に行かせてください」のように訳せます。

依頼は命令より弱いという単純な丁寧度だけで定義せず、命令が命題の成立を要求するのに対し、依頼は聞き手へ成立を求める発話行為として扱います。

## 情報源・認識態度

情報がどこから得られたか、または話者がどのような根拠と責任で提示するかを表します。

| 仮称 | 意味 |
|---|---|
| `直接確認` | 話者が直接見聞き、経験、確認した |
| `伝聞` | 他者、文書、報道などから得た |
| `推論` | 観察可能な証拠から結論を導いた |
| `不確定` | 根拠または確信が不足している |
| `断定` | 情報源を示さず、話者が事実として提示する |
| `想定` | 経験則、常識、傾向、先入観などを根拠に判断する |

`断定` は命題が客観的に真であることを保証せず、話者が事実として提示したことを示します。

`想定` は英語の *assumptive* に近い分類です。具体的な証拠に基づく `推論` とは区別します。また、`想定` を使うことで、偏見や先入観に基づく判断であることも明示できます。

```text
壊れる 過去 直接確認 機械
壊れる 過去 伝聞 機械
壊れる 過去 推論 機械
壊れる 過去 不確定 機械
壊れる 過去 断定 機械
壊れる 過去 想定 機械
```

情報源・認識態度は文全体に作用するため、述語を構成する助動詞の最後に置きます。
