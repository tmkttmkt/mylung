# 文の種類と助動詞

文の種類、時制、相、否定、話者の判断、情報源は、動詞の直後に置く助動詞で表します。

否定助動詞には語形が決まっています。それ以外の助動詞の日本語名は説明用の仮称です。表記方法については [文法資料の表記](README.md#文法資料の表記) を参照してください。

助動詞は語彙上の機能語として扱います。現在の一覧は [機能語：助動詞](../words/function-words.md#助動詞) にあります。

## 基本形

助動詞を含む述語全体を文頭に置き、その後に主語と目的語を置きます。

```text
動詞 助動詞* 主語 目的語
```

助動詞は必要なものだけを使用します。通常の肯定文には、文が断定文であることだけを示す専用助動詞を必要としません。

## 助動詞境界の非正式な省略

正式表記では、動詞と助動詞の間、および助動詞同士の間に単語区切り `0` を置きます。非正式な表記では、この位置の `0` だけを省略できます。

```text
D1F280E30D2 → 正式表記：話す0否定0命令
D1F28E3D2   → 非正式表記：話す＋否定＋命令
```

省略しても、助動詞は品詞上独立した機能語として扱います。名詞・代名詞・助詞などとの境界にある `0` は省略できません。

```text
D1F2801 → 話す0私：正しい
D1F281  → 不成立または別の一語として解釈する
```

## 助動詞の順序

複数の助動詞を使う場合は、基本的に次の順序で並べます。

```text
動詞 → 相 → 時制 → 否定 → 法 → 文の用途 → 情報源・認識態度
```

この順序は暫定であり、例文を作りながら調整します。

## 時制

| 仮称 | 意味 |
|---|---|
| 無標 | 時制と一時性を指定しない |
| `現況` | 発話時点で一時的に成立している |
| `過去` | 発話時点より前に成立した |
| `未来` | 発話時点より後に成立する |

`現況` は一般的な現在時制ではなく、その状態が一時的であることを明示します。

```text
住む 現況 私 東京
```

「私は現在、一時的に東京に住んでいる」

```text
住む 私 東京
```

時期や一時性を明示しない「私は東京に住む／住んでいる」

## 相

最初に次の二つを用意します。

| 仮称 | 意味 |
|---|---|
| `進行` | 動作が進行中である |
| `完了` | 動作が完了している |

```text
読む 進行 私 本
読む 完了 過去 私 本
```

## 否定

否定助動詞は `E3` です。否定する述語または形容詞の直後に置き、その作用域を否定します。

```text
読む E3 私 本
```

「私は本を読まない」

禁止専用の助動詞は作らず、`否定` と `命令` を組み合わせます。

```text
読む E3 命令 あなた 本
```

「本を読むな」

決定済みの語だけを使った例：

```text
D1F280E301000
```

「私は話さない。」

```text
B1B280E3010810D1F2D185E56072000
```

「私は人間ではない。」

## 法

| 仮称 | 意味 |
|---|---|
| `可能` | 能力または状況により実現できる |
| `推量` | 話者が命題の成立を推測する |
| `願望` | 主語が動詞の表す出来事の実現を望む |

`推量` と後述する `不確定` の違いは、例文を作りながら検討します。

`願望` は独立した「欲する」という動詞を作らず、動詞に付く助動詞として表します。

```text
読む 願望 1 本
持つ 願望 1 本
```

「私は本を読みたい」「私は本を持ちたい／本が欲しい」

## 文の用途

| 仮称 | 意味 |
|---|---|
| `疑問` | 相手に真偽や不足情報を問う |
| `D2` | 命令。相手に行為を求める |
| `依頼` | 相手に行為を丁寧に求める |

```text
読む 疑問 あなた 本
読む D2 あなた 本
読む 依頼 あなた 本
```

命令では、聞き手である主語を文脈から省略できます。

```text
D1F280D2000
```

「話せ。」

否定 `E3` を命令 `D2` の前に置くと禁止になります。

```text
D1F280E30D2000
```

「話すな。」

## 情報源・認識態度

情報がどこから得られたか、または話者がどのような根拠と責任で提示するかを表します。

| 仮称 | 意味 |
|---|---|
| `直接確認` | 話者が直接見聞き、経験、確認した |
| `伝聞` | 他者、文書、報道などから得た |
| `推論` | 観察可能な証拠から結論を導いた |
| `不確定` | 根拠または確信が不足している |
| `断定` | 情報源を示さず、話者が事実として提示する |
| `想定` | 経験則、常識、傾向、先入観などを根拠に判断する |

`断定` は命題が客観的に真であることを保証せず、話者が事実として提示したことを示します。

`想定` は英語の *assumptive* に近い分類です。具体的な証拠に基づく `推論` とは区別します。また、`想定` を使うことで、偏見や先入観に基づく判断であることも明示できます。

```text
壊れる 過去 直接確認 機械
壊れる 過去 伝聞 機械
壊れる 過去 推論 機械
壊れる 過去 不確定 機械
壊れる 過去 断定 機械
壊れる 過去 想定 機械
```

情報源・認識態度は文全体に作用するため、述語を構成する助動詞の最後に置きます。
