# 助詞

名詞の役割や、語同士の関係を示す機能語を管理します。

助詞は日本語の助詞と一対一に対応させず、複数の近い関係をまとめて示します。ただし、同じ文の中で区別する必要が生じやすい関係は別の助詞にします。

助詞の具体的な語形は [単語の助詞](../words/particles.md) で定義します。助詞は子音字と母音字からなる一音節の独立語で、助詞が付く語との間にも単語区切り `0` を置きます。

## 格関係を示す助詞

| 分類 | 中心的な働き | 含める関係 |
|---|---|---|
| 主体 | 文の中心となる参加者 | 動作者、経験者、状態の主体 |
| 対象 | 動作や認識が向けられるもの | 作用対象、認識対象、発話内容 |
| 到達・存在 | ある点へ結び付くもの | 受け手、目的地、存在位置、変化後の状態 |
| 場所・手段 | 動作を成立させる環境や媒介 | 動作場所、道具、方法、媒体、材料 |
| 起点 | そこから始まるもの | 出発点、時間的起点、情報源、原因 |
| 随伴 | 対等に関与するもの | 共同者、相互関係、比較相手 |
| 所属 | 名詞同士の帰属関係 | 所有、所属、部分、種類 |

同定動詞の同定先には `72` を使用します。この用法では、移動先ではなく、対象が結び付けられる分類・性質・個体を示します。

### 場所と手段の統合

動作場所と手段は、どちらも「動作が成立する環境・媒介」とみなし、同じ助詞で示します。

```text
部屋［場所・手段］話す     → 部屋で話す
電話［場所・手段］話す     → 電話で話す
言語［場所・手段］話す     → その言語を使って話す
木［場所・手段］作る       → 木を材料として作る
```

関係の細部は、名詞と動詞の意味および文脈から判断します。

存在する場所は動作の環境ではなく、存在物が結び付く位置として `到達・存在` で示します。

```text
人が 部屋0 72 存在する → 人が部屋にいる
人が 部屋0 93 話す     → 人が部屋で話す
```

## 省略

標準のVSO語順で役割が明らかな場合、主体と対象の助詞は省略できます。語順を変更した場合や役割が曖昧になる場合は助詞を付けます。

それ以外の助詞をどこまで省略できるかは未決定です。

## 話題と焦点

話題や焦点を示す形式は、格関係とは別に設ける予定です。同じ名詞に格と話題・焦点の両方を示せるかは未決定です。

## 所属助詞の語順

所属助詞 `A5` は所有者・所属元の後ろに置き、その後ろに被所有物・所属する名詞を必要とします。

```text
人間0 A5 機械 → 人間の機械
```

`A5` は名詞同士を結ぶ助詞であり、それ自体を同定動詞の同定先にはできません。したがって、次の文は後続する名詞が欠けているため不成立です。

```text
B1B28010810D1F2D185E560A5
同定する 私‐主体 人間‐所属……
```

これは「私は人間に属する」ではなく、「私は、人間の……」で途切れた形になります。

随伴助詞 `B2` を個体同士の同一性の表現にも使用するかは保留します。
