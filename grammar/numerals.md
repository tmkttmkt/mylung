# 数詞

## 基数

数は16進法を基本とし、実際の数字には `0`〜`9` と `A`〜`F` をそのまま使用します。

## 数と数字列

`15` は後続する数字列を一つの数として扱う開始標識で、`51` を終了標識とします。`14` は後続する文字を、各桁を明示した数字列として扱う開始標識です。

```text
15FF51      → 一つの数 FF₁₆
15F0051     → 一つの数 F00₁₆
14FF8241    → 数字列 FF。末尾の桁を16⁰の位とする
```

`15` 形式では、開始標識 `15` と終了標識 `51` の間を16進数の数字列として読みます。終了に `0` を使用しないため、数字 `0` を数値内部にそのまま書けます。

```text
15 d(n) ... d(1) d(0) 51
```

数字列では末尾に `8241`（16⁰の位）を置きます。最後の数字が16⁰の係数、その一つ前が16¹の係数となり、左へ進むごとに指数が一つ増えます。

```text
14 d(n) ... d(1) d(0) 8241
```

この終端方法でも `0` を終了記号に使わないため、数字列内部のゼロをそのまま書けます。

```text
14302408241
```

これは数字列 `30240` であり、次の値を表します。

```text
3×16⁴ + 0×16³ + 2×16² + 4×16¹ + 0×16⁰
```

## 色での利用

色核は独立核 `F2A3` とします。光核 `F2A1` と語形を近づけますが、光核や可視光核 `E1B3F2A1` から派生した核ではありません。

数値で色を指定する場合、色核 `F2A3` を数値の単位語として後置します。数値と色核は別語なので、実際の表記では単語境界 `0` を置きます。

```text
15 d(n) ... d(0) 51 0 F2A3
```

例えば、ある色空間で `ABC` が一つの色値を表す場合は次のように書きます。

```text
15ABC510F2A3
```

これは「数値 ABC の色」を表します。色核は数値を色値として解釈させる単位であり、数値そのものの構文は通常の `15 ... 51` 形式と同じです。

色空間、各成分の桁数、成分の並び順は別途決定します。したがって現時点では `ABC` が具体的にどの色を指すかまでは定めません。

例えば将来 RGB を各8ビットで採用する場合、16進表記 `FF0000` は次の形になります。

```text
15FF0000510F2A3
```

これは RGB を正式採用する例ではなく、色核を数値の単位として使う構文例です。

## 位

`82` を数の大きさ・位に関係する共通部分とします。4桁ブロック内部の単位は次の四つです。

| 単位語 | 値 |
|---|---:|
| `8241` | 16⁰ |
| `8242` | 16¹ |
| `8243` | 16² |
| `8245` | 16³ |

中央の `4` は `2` と末尾の母音を分けます。末尾の `1・2・3・5` は、この分野では第0・第1・第2・第3段階に対応します。

## 4桁ごとの大単位

4桁ごとの大単位は次の一般式で作ります。

```text
大単位(k) = 8254 + 全単射4進表記(k)
値         = 16^(4k)
```

`k` は1以上の整数です。最初の単位は次のようになります。

| 単位語 | k | 値 |
|---|---:|---:|
| `82541` | 1 | 16⁴ |
| `82542` | 2 | 16⁸ |
| `82543` | 3 | 16¹² |
| `82545` | 4 | 16¹⁶ |
| `8254141` | 5 | 16²⁰ |
| `8254142` | 6 | 16²⁴ |
| `8254143` | 7 | 16²⁸ |
| `8254145` | 8 | 16³² |
| `8254241` | 9 | 16³⁶ |

## 大単位番号の全単射4進表記

全単射4進表記では、ゼロを使わず、四つの母音字を数字として使用します。

| 値 | 桁字 |
|---:|---|
| 1 | `1` |
| 2 | `2` |
| 3 | `3` |
| 4 | `5` |

複数桁では各桁の間に `4` を置きます。

| 値 | 通常の全単射4進 | この言語での表記 |
|---:|---|---|
| 1 | 1 | `1` |
| 2 | 2 | `2` |
| 3 | 3 | `3` |
| 4 | 4 | `5` |
| 5 | 11 | `141` |
| 6 | 12 | `142` |
| 7 | 13 | `143` |
| 8 | 14 | `145` |
| 9 | 21 | `241` |

この方式により、16¹⁶より大きい単位も有限個の規則から無限に生成できます。
