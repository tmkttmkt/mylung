# 数詞

## 基数

数は16進法を基本とし、実際の数字には `0`〜`9` と `A`〜`F` をそのまま使用します。

## 数と数字列

`15` は後続する数字列を一つの数として扱う開始標識です。`14` は後続する文字を、各桁を明示した数字列として扱う開始標識です。

```text
15FF0       → 一つの数 FF₁₆
14FF8241    → 数字列 FF。末尾の桁を16⁰の位とする
```

数字列では末尾に `8241`（16⁰の位）を置きます。最後の数字が16⁰の係数、その一つ前が16¹の係数となり、左へ進むごとに指数が一つ増えます。

```text
14 d(n) ... d(1) d(0) 8241
```

この終端方法では `0` を終了記号に使わないため、数字列内部のゼロをそのまま書けます。

```text
14302408241
```

これは数字列 `30240` であり、次の値を表します。

```text
3×16⁴ + 0×16³ + 2×16² + 4×16¹ + 0×16⁰
```

`15` で始める一体的な数値表記については、数字 `0` と終了標識 `0` の区別方法がまだ未決定です。

## 位

`82` を数の大きさ・位に関係する共通部分とします。4桁ブロック内部の単位は次の四つです。

| 単位語 | 値 |
|---|---:|
| `8241` | 16⁰ |
| `8242` | 16¹ |
| `8243` | 16² |
| `8245` | 16³ |

中央の `4` は `2` と末尾の母音を分けます。末尾の `1・2・3・5` は、この分野では第0・第1・第2・第3段階に対応します。

## 4桁ごとの大単位

4桁ごとの大単位は次の一般式で作ります。

```text
大単位(k) = 8254 + 全単射4進表記(k)
値         = 16^(4k)
```

`k` は1以上の整数です。最初の単位は次のようになります。

| 単位語 | k | 値 |
|---|---:|---:|
| `82541` | 1 | 16⁴ |
| `82542` | 2 | 16⁸ |
| `82543` | 3 | 16¹² |
| `82545` | 4 | 16¹⁶ |
| `8254141` | 5 | 16²⁰ |
| `8254142` | 6 | 16²⁴ |
| `8254143` | 7 | 16²⁸ |
| `8254145` | 8 | 16³² |
| `8254241` | 9 | 16³⁶ |

## 大単位番号の全単射4進表記

全単射4進表記では、ゼロを使わず、四つの母音字を数字として使用します。

| 値 | 桁字 |
|---:|---|
| 1 | `1` |
| 2 | `2` |
| 3 | `3` |
| 4 | `5` |

複数桁では各桁の間に `4` を置きます。

| 値 | 通常の全単射4進 | この言語での表記 |
|---:|---|---|
| 1 | 1 | `1` |
| 2 | 2 | `2` |
| 3 | 3 | `3` |
| 4 | 4 | `5` |
| 5 | 11 | `141` |
| 6 | 12 | `142` |
| 7 | 13 | `143` |
| 8 | 14 | `145` |
| 9 | 21 | `241` |

この方式により、16¹⁶より大きい単位も有限個の規則から無限に生成できます。
