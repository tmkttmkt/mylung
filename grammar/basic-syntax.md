# 基本構文

## 基本語順

基本語順はVSO（動詞・主語・目的語）とします。

```text
読む 私 本
```

標準語順では、主語と目的語を示す助詞を省略できます。助詞を付ければ、意味を保ったまま語順を変更できます。

```text
読む 私・主 本・対
本・対 読む 私・主
```

語順を変えた場合、文頭へ移動した要素は話題や強調として解釈されます。

詳しい規則は検討中です。

## 動詞の項と自動詞・他動詞

現段階では、動詞を語彙上の「自動詞」「他動詞」という二種類へ固定分類しません。

動詞は作用・動作・変化・遷移・関係などの射を表し、その射に参加する項の役割は、語順と助詞によって表します。特に、主体には `81`、対象には `63` を用います。

```text
E1C5D8580C1D5081
```

「戦争が成立する／戦争が始まる」

```text
E1C5D858010810C1D5063
```

「私が戦争を成立させる／私が戦争を始める」

この二文では同じ動詞 `E1C5D858`（成立する・生じる）を使用し、射に対する各項の役割を助詞で区別します。したがって、項の数が変わるたびに別の自動詞・他動詞を必ず用意することはしません。

標準VSOで役割が明らかな場合は、従来どおり主体助詞 `81` と対象助詞 `63` を省略できます。ただし、同じ動詞が複数の項構造を取りうる場合など、曖昧さを避ける必要があるときは助詞を明示します。

この方針は、すべての動詞で任意に主体や対象を追加できることを意味しません。各動詞が意味上どのような項を取りうるかは、その動詞が表す射の意味によって決まります。
