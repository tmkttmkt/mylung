# 修飾

形容、所有、数量、関係節など、名詞や動詞を詳しく説明する規則を管理します。

修飾語を被修飾語の前後どちらに置くかは未定です。ただし、数量と単位に対象概念・射概念を組み合わせる構文では、暫定的に `数量 + 単位 + 概念型 + 被修飾語` の順を使用します。

## 対象概念と射概念

`C65` を対象概念、`D85` を射概念とします。

- `C65`：ある時点・文脈で一つの対象、状態、値、配置として捉える
- `D85`：対象または状態の間に成立する作用、動作、運動、変化、遷移、過程として捉える

対象概念は無標の既定解釈とし、文脈から明らかな場合は `C65` を省略できます。射概念として解釈させる場合は `D85` を明示します。

この区別は品詞標識 `6` と `8` そのものではありません。`6` が具体・対象・事例、`8` が動作・変化・過程という文字イメージを持つことを取り込みつつ、それらを一般化した意味核として `C65` と `D85` を使用します。

例えば、時間単位に数を組み合わせた表現では、対象概念は暦上の位置・区間、射概念は時間の経過量として解釈できます。

## 年を使う例

年の意味核は `B855` です。

十進数の2000は16進数では `7D0` なので、一つの数としては次のように表します。

```text
157D051
```

### 2000年の戦争

```text
157D051 B855 C65 C1D5
```

`C65` によって `157D051 B855` を暦上の一つの年区間として捉え、「2000年の戦争」を表します。対象概念は既定解釈なので、通常は次のように省略できます。

```text
157D051 B855 C1D5
```

暦体系を明示しない場合は文脈上の既定の暦を使用します。現代の地球社会を前提とする通常の文脈では、西暦2000年を暗示できます。別の暦を使う必要がある場合は、暦体系を別途明示します。

### 2000年間の戦争

```text
157D051 B855 D85 C1D5
```

`D85` によって `157D051 B855` を時間の経過として捉え、「2000年間続く戦争」を表します。これは暦上の2000年という位置を指すのではなく、2000年という長さを持つ射的・過程的な時間量です。
