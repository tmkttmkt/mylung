# 性質語

性質語は、対象の状態、特徴、評価などを表す語彙上の分類です。意味核に形容詞標識を付けた形容詞形を持ちますが、状態動詞にはしません。派生方法は [意味核と品詞標識](../grammar/morphology.md#意味核と品詞標識) を参照してください。

形容詞は名詞と動詞の両方を形容できます。動詞を形容する場合も副詞とは呼ばず、同じ形容詞形を使用します。性質を述べる文では、形容詞形を同定動詞の補語として使用します。

形容詞は別の形容詞も形容できます。暫定的に形容詞は被形容語の後ろに置き、形容詞同士を並列する場合と、一方がもう一方を限定する場合は弱い境界 `00` の位置で区別します。詳しくは [語形成の形容詞の扱い](../grammar/morphology.md#形容詞の扱い) を参照してください。

```text
同定する 3 大きい
```

「それは大きい」

```text
同定する 否定 3 良い
```

「それは良くない」

```text
同定する 現況 3 赤い
```

「それは現在、一時的に赤い」

性質そのものが存在することを述べる場合に限り、存在動詞を使用できます。

```text
存在する 痛み 1・場所
```

「私に痛みがある」

## 尺度と大小

尺度上の大きい側を表す基本核を `85` とします。

```text
85
```

`85` は特定の長さ・数量・温度などに限定せず、ある尺度上で値・程度が大きい側を表します。反対側の小は、否定・不成立核 `E35` と大核を組み合わせます。

```text
E3585
```

したがって形容詞形は次の通りです。

```text
85A       大きい
E3585A    小さい
```

一般の尺度語では、尺度核の後ろに `85` または `E3585` を置いて両側を作ります。

```text
尺度 + 85       → その尺度で大きい側
尺度 + E3585    → その尺度で小さい側
```

例えば `C25` を広がり・長さ、`D25` を強度、`D35` を温度とします。

```text
C2585A       長い
C25E3585A    短い

D2585A       強い
D25E3585A    弱い

D3585A       熱い
D35E3585A    冷たい
```

`E3` による文法的否定とは区別します。

```text
D2585A 0 E3     → 強くない
D25E3585A       → 弱い
```

前者は強いという性質が成立しないことだけを表し、後者は強度尺度の小さい側として語彙化された性質です。

## 数量と多少

数量の意味核を `825` とします。

```text
825
```

多は数量と大を組み合わせます。

```text
82585
```

少だけは尺度語の一般的な `尺度 + 小` 型を使わず、多という概念全体の反対側として `E35` を前置して語彙化します。

```text
E3582585
```

したがって次の対になります。

```text
82585A       多い
E3582585A    少ない
```

この「少」の作り方は数量語系の特例であり、他の尺度語へ一般化しません。

## 距離と近い・遠い

近・遠を独立した基本対とはせず、距離尺度と大小へ還元します。距離の意味核を `B25` とします。

```text
B25
```

距離が大きい側が遠、距離が小さい側が近です。

```text
B2585       遠隔・遠さ
B25E3585    近接・近さ
```

形容詞形は次の通りです。

```text
B2585A       遠い
B25E3585A    近い
```

数学的には、基準空間に距離 `d` が定義されているとき、`B25E3585` は `d(x,y)` が小さい側、`B2585` は `d(x,y)` が大きい側を表します。基準空間は物理空間に限定せず、時間、年齢、概念空間などにも使用できます。特定の距離関数や計算法は `B25` 自体では固定しません。

単なる文法的否定とも区別します。

```text
B25E3585A 0 E3    → 近くない
B2585A             → 遠い
```

「近くない」は中間的距離も許しますが、「遠い」は距離尺度の大きい側として語彙化されています。

## 範囲と密・疎

範囲・領域の意味核を `C35` とします。

```text
C35
```

密・疎は独立した密度尺度を原始概念として置かず、範囲と多少から構成します。

```text
C3582585       範囲 + 多 = 密
C35E3582585    範囲 + 少 = 疎
```

形容詞形は次の通りです。

```text
C3582585A       密な・密集した
C35E3582585A    疎な・まばらな
```

ここでいう範囲は物理的な面積・体積だけに限定せず、文脈上の領域に対して、その内部に対象が多いか少ないかを表します。

## 独立させる尺度

すべての対を数量や距離へ還元せず、日常的・概念的に独立性が高い尺度は個別の尺度核を持たせます。

```text
C2D5    剛性
C5B5    安定性
E1B5    確実性
```

それぞれ大小を用いて次の対を作ります。

```text
C2D585A       硬い
C2D5E3585A    柔らかい

C5B585A       安定した
C5B5E3585A    不安定な

E1B585A       確実な
E1B5E3585A    不確実な
```

確実性は認識的な確からしさを表す尺度であり、疑問という文用途や文法的否定とは別概念です。

## 速度について

速度は現時点では語形を確定しません。

`D85` は射・変化・過程、`B85` は時間を表しますが、単純な `D85B85` という連結だけでは「単位時間あたりの変化量」という比率を表現できません。そのため、比・率・単位あたりの構成規則を決めるまで速度核と速い・遅いの語形は保留します。

## 老人・若者と破

老人と若者は、暦年齢そのものではなく、死との距離で定義します。

```text
老人 = 死 + 距離 + 小 + 人間
若者 = 死 + 距離 + 大 + 人間
```

語形は次の通りです。

```text
E1C5B15E35C541B25E3585D1F2D185E5    老人
E1C5B15E35C541B2585D1F2D185E5       若者
```

この定義では、老人は基準空間上で死との距離が小さい人間、若者は死との距離が大きい人間です。したがって暦年齢と完全には一致せず、基準空間の取り方によって評価が変わりえます。

老害・若害は、老人・若者の内部に `破` を埋め込むのではなく、それぞれの完成した概念と `C3D5` を並列に複合します。

```text
老害 = 老人 + 破
若害 = 若者 + 破
```

語系ツリーは次の通りです。

```text
老害
├─ 老人
│  ├─ 死
│  │  ├─ 存在 E1C5
│  │  ├─ 不可逆 B15E35
│  │  │  ├─ 再・再成立 B15
│  │  │  └─ 否定・不成立 E35
│  │  └─ 終了 C541
│  ├─ 近接 B25E3585
│  │  ├─ 距離 B25
│  │  └─ 小 E3585
│  └─ 人間
│     ├─ 言語活動 D1F2
│     └─ 生命 D185E5
└─ 破 C3D5
```

若害は `近接 B25E3585` を `遠隔 B2585` に置き換えた対称形です。

```text
E1C5B15E35C541B25E3585D1F2D185E5C3D5    老害
E1C5B15E35C541B2585D1F2D185E5C3D5       若害
```

`破` は老人・若者という属性そのものを悪とする印ではなく、その対象を `破` として評価する複合概念です。

高低・広狭・深浅については空間軸の語系を決めてから、広がりと大小を組み合わせて作る予定です。名詞を直接修飾する構文、比較、程度表現は未決定です。
