# 性質語

性質語は、対象の状態、特徴、評価などを表す語彙上の分類です。意味核に形容詞標識を付けた形容詞形を持ちますが、状態動詞にはしません。派生方法は [意味核と品詞標識](../grammar/morphology.md#意味核と品詞標識) を参照してください。

形容詞は名詞と動詞の両方を形容できます。動詞を形容する場合も副詞とは呼ばず、同じ形容詞形を使用します。性質を述べる文では、形容詞形を同定動詞の補語として使用します。

形容詞は別の形容詞も形容できます。暫定的に形容詞は被形容語の後ろに置き、形容詞同士を並列する場合と、一方がもう一方を限定する場合は弱い境界 `00` の位置で区別します。詳しくは [語形成の形容詞の扱い](../grammar/morphology.md#形容詞の扱い) を参照してください。

```text
同定する 3 大きい
```

「それは大きい」

```text
同定する 否定 3 良い
```

「それは良くない」

```text
同定する 現況 3 赤い
```

「それは現在、一時的に赤い」

性質そのものが存在することを述べる場合に限り、存在動詞を使用できます。

```text
存在する 痛み 1・場所
```

「私に痛みがある」

## 近い・遠い

近接の意味核を `B21` とします。

```text
B21
```

ある基準空間において、二つの対象間の距離が小さい関係を表します。基準空間は物理空間に限定せず、時間、年齢、概念空間などにも使用できます。

```text
B21A
```

`B21` に形容詞標識 `A` を付けた「近い」です。

数学的には、基準空間に距離 `d` が定義されているとき、対象 `x` と `y` の `d(x,y)` が小さいこととして解釈できます。内積空間では、対象を単位ベクトルへ正規化した場合、内積が大きいほどユークリッド距離が小さくなるため、近接性の数量化に対応させられます。ただし `B21` 自体は特定の距離関数や内積の計算法を固定しません。

遠隔・遠さは、否定核 `E35` と近接核を組み合わせた複合核として語彙化します。

```text
E35B21
```

形容詞形は次の通りです。

```text
E35B21A
```

これは「遠い」を表します。

単なる文法的否定とは区別します。

```text
B21A 0 E3     → 近くない
E35B21A       → 遠い
```

`B21A 0 E3` は「近い」という性質が成立しないことだけを表し、中間的な距離も含められます。`E35B21A` は、距離が大きい側の性質として辞書上「遠い」に固定した語です。

仮読みでは、基本読みプロファイルに従って次のようになります。

```text
B21       /tia/      近接・近さ
B21A      /tias/     近い
E35B21    /luo.tia/  遠隔・遠さ
E35B21A   /luo.tias/ 遠い
```

名詞を直接修飾する構文、比較、程度表現は未決定です。
