# 語根

派生語や複合語のもとになる語根と、その関係を記録します。

各文字も意味を持ちますが、一般語では複数の文字からなる語根を基本的な意味核とします。文字の意味は語根の語源、連想、ニュアンスに影響し、語根の意味を単純な足し算だけで決定するものではありません。

語根は単語の意味核として扱います。母音字で終わる核単体は概念・抽象を表し、名詞・動詞・形容詞の品詞標識を付けて派生語を作ります。詳しくは [意味核と品詞標識](../grammar/morphology.md#意味核と品詞標識) を参照してください。

### 生命核

```text
D185E5
```

- `D1`：自己の力・自己作用
- `85`：全体に及ぶ過程
- `E5`：存在全体・持続する存在

### 機械核

```text
C1D25
```

- `C1`：内部構造
- `D2`：対象へ作用する力
- `5`：統合された全体

単純な道具から複雑な装置までを含む、機械一般の意味核です。情報処理機械はこの核自体には含意せず、情報処理を表す核を前置した複合語として後から作ります。

```text
情報処理核 + C1D25 + `6` → 情報処理機械
```

### 言語活動核

```text
D1F2
```

- `D1`：自己から生じる意図的作用
- `F2`：意味を相手へ向ける

言語体系を用いて意味を構成し、相手とやり取りする活動を表します。

### 発言核

```text
E1F1
```

特定の内容を、一回の言語表現として外へ出すことを表します。継続的な言語活動や会話を表す `D1F2` と区別します。

### 視覚核

```text
E1B3
```

自己を中心として、外部の対象を視覚によって捉えることを表します。意図的に目を向ける動作には限定しません。

### 存在核

```text
E1C5
```

- `E1`：自己・中心を持つ存在
- `C5`：一つの全体として成立する形

人、物、出来事、状態などが、一つの存在として成立していることを表します。

### 同定核

```text
B1B2
```

- `B1`：中心となる対象からの関係
- `B2`：対応する相手への関係

対象を、別の対象、分類、性質へ対応付けることを表します。同一性、分類、性質記述に使用します。

### プログラム核

```text
D3B2
```

- `D3`：外部の対象へ働きかける作用
- `B2`：対象を後の行き先・対応関係へ結び付ける

ある実行者が後にたどることで過程を現実にできるよう、状態、関係、分岐などをあらかじめ構成することを表します。機械による実行には限定しません。

```text
D3B26 → プログラム、実行可能な構成
D3B28 → プログラムする
D3B2A → プログラムされた、予定された
```

地図、旅程、レシピ、楽譜、設計図、機械用プログラムなどは、それぞれ空間、移動、調理、演奏、建築、機械動作に関するプログラムとして複合語を作れます。

### 摂取・消費核

```text
D3E5
```

- `D3`：外部にある対象・資源への作用
- `E5`：一つの存在または過程の成立・持続

主体が外部の資源を取り込み、変換または消費することで、自身の活動、状態、過程を成立または継続させることを表します。資源が単に内部へ移動するだけでなく、元の形または利用可能性を失いながら主体の過程に使われることを含みます。

生命専用の概念ではありません。主体と資源に応じて、日本語では異なる動詞に訳します。

```text
人間 + 食物       → 食べる
人間 + 液体       → 飲む
機械 + 電気・燃料 → 電力・燃料を消費する
火 + 可燃物       → 燃やして持続する
プログラム + 記憶 → メモリを消費する
```

```text
D3E56 → 摂取物、食物、燃料、消費資源
D3E58 → 食べる、飲む、消費する
D3E5A → 摂取・消費に関係する
```

### 破核

```text
C3D5
```

- `C3`：外部へ現れた形・構造の変化
- `D5`：全体へ及ぶ作用または評価

話者または文脈上の評価基準から見て、あってはならない、醜い、または悪いと評価される状態・性質を表します。実際の損害、加害意思、防止能力の欠如は破核だけでは指定しません。

破核は原則として単独の評価語にはせず、意思核または能力核と組み合わせた複合核で使用します。日常的な「あれは悪い」「これは醜い」を破核だけで表すことは避け、何の意思または能力に破があるのかを明示します。

### 意思核

```text
B2E1D1
```

- `B2`：選ばれた結果との対応関係
- `E1`：存在・知覚・意識の中心
- `D1`：自己を起点とする作用

複数の可能性から結果を選び、自己の作用をその結果へ方向付けることを表します。欲求、選択、意図、決意を含みますが、それを実現する能力や実際の結果は含みません。

### 能力核

```text
B262D5
```

- `B2`：特定の結果との対応関係
- `62`：具体的な対象へ働き掛けられる状態
- `D5`：全体として備わる作用力

ある結果を起こす、防ぐ、維持する、または変えることが可能である状態を表します。知識、身体能力、道具、資源、権限、および集団が持つ保護能力を含みます。

### 物質核

```text
E5C3
```

物理的に存在し、構造や作用の担い手となるものを表します。個別の物体だけではなく、水、金属、空気などの物質や材料を含む基礎概念です。存在一般を表す `E1C5` より範囲を物理的なものへ限定します。

### 概念核

```text
C1F5
```

意味や概念として成立する内容を表します。物理的な実体を必要とせず、分類、考え、意味内容などを含みます。mylungの語形成でいう「意味核」そのものも、この概念の一種として扱います。

### 反照核

```text
B3D1
```

対象・出来事・作用を、その起点または自己側へ戻して再び捉えることを表します。日本語名は「反照核」とします。

物理的な光や像の反射だけでなく、過去の行為や出来事を自己側へ向け直して捉える「振り返り」「省察」「反省」も同じ抽象過程として含みます。反省に過失や否定的評価があることまでは、この核だけでは指定しません。

### 光核

```text
F2A1
```

起点から方向をもって伝わる物理的作用を表します。人間や特定の生物に見えることは光核自体には含めず、可視性は別の核との複合で表します。

語形では、比較的使用頻度の低い `F` と `A` を含め、既存の高頻度文字への偏りを抑えます。文字の意味は単純な加算規則ではありませんが、`F2` は方向を持つ伝達、`A1` は起点側に成立する性質・状態を連想させます。

### 可視光核

```text
E1B3F2A1
```

視覚核 `E1B3` と光核 `F2A1` を組み合わせた複合核です。視覚によって捉えられる光を表します。

```text
E1B3 + F2A1 → E1B3F2A1
```

色核は可視光核から派生させず、独立した意味核として扱います。

### 色核

```text
A3F2
```

視覚的に区別される色の概念を表す独立核です。可視光核 `E1B3F2A1` と意味上の関係はありますが、語形成上の派生関係にはしません。

語形では比較的使用頻度の低い `A` と `F` を含め、光核 `F2A1` とも十分に異なる形にします。

数値で色を指定するときは、この色核を数値の単位語として使用します。数値構文は [数詞](../grammar/numerals.md#色での利用) を参照してください。

### 物事と鏡の複合核

```text
E5C3C1F5 → 物事
B3D1E5C3 → 鏡
```

物事核は、物質核 `E5C3` と概念核 `C1F5` を組み合わせ、物理的なものと概念的なものを包括して、認識・言及・作用の対象となりうるものを表します。

鏡核は、反照核 `B3D1` を修飾核、物質核 `E5C3` を中心核として組み合わせます。視覚像をその起点側へ返す反照性を持つ物質という構成です。

### 意思・能力と破の複合核

```text
B2E1D1C3D5 → 加害者側の破
B262D5C3D5 → 被害者側の破
```

加害者側の破は、破に結び付く行為または態度を自ら選ぶことを表します。悪い結果そのものを望んでいる必要はなく、不注意な選択や軽い落ち度にも使用できます。実現能力や実害の発生は必要としません。

被害者側の破は、本人または本人が属する集団で、破を防止、回避、停止する能力がその場で有効に成立していないことを表します。恒常的な無能力だけでなく、表示、準備、連絡、規則などによって使える状態にされていなかった防止能力も含みます。本人の責任や人格への非難を必ずしも含みません。二つの複合核は同じ出来事について独立して成立し、両立できます。

どちらの語も重大さを語義に固定しません。犯罪や災害を論じる重い用法から、食べ物の取り違えや遊びの失敗を指す軽い悪口まで、深刻さ、非難の強さ、冗談かどうかは出来事、口調、話者間の関係などの文脈から判断します。

### 四季の核

季節 `C3B5`、春 `1C3B5`、夏 `2C3B5`、秋 `3C3B5`、冬 `543B5` は、すべてそれぞれ独立した核です。春・夏・秋が季節核から作られる複合核という扱いにはしません。

ただし語形には意図的な類似を持たせ、季節に関係する語であることを連想しやすくします。この類似は語源・連想上の関係であり、語形成上の分解規則ではありません。

| 季節 | 核 | 語形上の連想 |
|---|---|---|
| 季節 | `C3B5` | 季節一般の核 |
| 春 | `1C3B5` | `1` が開始・再生を連想させる |
| 夏 | `2C3B5` | `2` が展開・活動期を連想させる |
| 秋 | `3C3B5` | `3` が第三段階・収束を連想させる |
| 冬 | `543B5` | `4` が休止・切れ目を連想させる |

### 冬核の解釈

```text
543B5
```

- `5`：一つの循環全体
- `4`：無・休止・内的な切れ目
- `3`：休止から次の段階への移行
- `B5`：次の循環へ結び付く全体

`4` は二つの母音の間に置かれる無子音字なので、`5` と `3` は別々の音節として発音します。

```text
543B56 → 冬、具体的な冬季
543B5A → 冬の、冬らしい
```
