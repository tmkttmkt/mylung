# 語根

派生語や複合語のもとになる語根と、その関係を記録します。

各文字も意味を持ちますが、一般語では複数の文字からなる語根を基本的な意味核とします。文字の意味は語根の語源、連想、ニュアンスに影響し、語根の意味を単純な足し算だけで決定するものではありません。

語根は単語の意味核として扱います。母音字で終わる核単体は概念・抽象を表し、名詞・動詞・形容詞の品詞標識を付けて派生語を作ります。詳しくは [意味核と品詞標識](../grammar/morphology.md#意味核と品詞標識) を参照してください。

## 決定した意味核

| 意味核 | 文字列 | 構成の解釈 |
|---|---|---|
| 生命 | `D185E5` | 自己作用する過程によって存在全体を維持する |
| 機械 | `C1D25` | 内部構造によって対象へ力を及ぼす統合体 |
| 言語活動 | `D1F2` | 自己の意味を相手へ作用させる |
| 発言 | `E1F1` | 特定の内容を一回の言語表現として外へ出す |
| 視覚 | `E1B3` | 自己を中心として外部対象を視覚的に捉える |
| 存在 | `E1C5` | 自ら一つの形を持ち、全体として成立している |
| 同定 | `B1B2` | 中心となる対象を、対応する対象・分類・性質へ結び付ける |
| 季節 | `C3B5` | 周期的に移り変わる環境状態 |
| 春 | `1C3B5` | 季節周期の開始・再生の時期 |
| 夏 | `2C3B5` | 季節周期が展開し、活動が強まる時期 |
| 秋 | `3C3B5` | 季節周期の第三段階・収束と移行の時期 |
| 冬 | `543B5` | 全体の循環の中にある不在・休止から移行する時期 |

### 生命核

```text
D185E5
```

- `D1`：自己の力・自己作用
- `85`：全体に及ぶ過程
- `E5`：存在全体・持続する存在

### 機械核

```text
C1D25
```

- `C1`：内部構造
- `D2`：対象へ作用する力
- `5`：統合された全体

単純な道具から複雑な装置までを含む、機械一般の意味核です。情報処理機械はこの核自体には含意せず、情報処理を表す核を前置した複合語として後から作ります。

```text
情報処理核 + C1D25 + `6` → 情報処理機械
```

### 言語活動核

```text
D1F2
```

- `D1`：自己から生じる意図的作用
- `F2`：意味を相手へ向ける

言語体系を用いて意味を構成し、相手とやり取りする活動を表します。

### 発言核

```text
E1F1
```

特定の内容を、一回の言語表現として外へ出すことを表します。継続的な言語活動や会話を表す `D1F2` と区別します。

### 視覚核

```text
E1B3
```

自己を中心として、外部の対象を視覚によって捉えることを表します。意図的に目を向ける動作には限定しません。

### 存在核

```text
E1C5
```

- `E1`：自己・中心を持つ存在
- `C5`：一つの全体として成立する形

人、物、出来事、状態などが、一つの存在として成立していることを表します。

### 同定核

```text
B1B2
```

- `B1`：中心となる対象からの関係
- `B2`：対応する相手への関係

対象を、別の対象、分類、性質へ対応付けることを表します。同一性、分類、性質記述に使用します。

### 四季の核

季節核は `C3B5` です。春・夏・秋は季節核の前に母音を置いて周期上の段階を区別します。冬は正則形 `5C3B5` ではなく、独立した形 `543B5` を使います。

| 季節 | 核 | 構造 |
|---|---|---|
| 季節 | `C3B5` | `C3-B5` |
| 春 | `1C3B5` | `1-C3B5` |
| 夏 | `2C3B5` | `2-C3B5` |
| 秋 | `3C3B5` | `3-C3B5` |
| 冬 | `543B5` | `5-4-3-B5` |

`C3` は状態・形の移行、`B5` は複数の段階が結び付いた全体を示します。冬の `4` は母音同士を別音節にする無子音字であると同時に、休止や切れ目を示します。

### 冬核の解釈

```text
543B5
```

- `5`：一つの循環全体
- `4`：無・休止・内的な切れ目
- `3`：休止から次の段階への移行
- `B5`：次の循環へ結び付く全体

`4` は二つの母音の間に置かれる無子音字なので、`5` と `3` は別々の音節として発音します。

```text
543B56 → 冬、具体的な冬季
543B5A → 冬の、冬らしい
```
