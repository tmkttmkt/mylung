# 数詞と数字の読み

文法と表記規則は [数詞](../grammar/numerals.md) を参照してください。

## 16進数字の読み

数字は実際には `0`〜`F` で書き、次の音節で読みます。

| 数字 | 読み | 数字 | 読み |
|---:|---|---:|---|
| `0` | `A1` | `8` | `C1` |
| `1` | `A2` | `9` | `C2` |
| `2` | `A3` | `A` | `C3` |
| `3` | `A5` | `B` | `C5` |
| `4` | `B1` | `C` | `D1` |
| `5` | `B2` | `D` | `D2` |
| `6` | `B3` | `E` | `D3` |
| `7` | `B5` | `F` | `D5` |

読みの音節は数値表記の中で数字を発音するためのものです。同形の助詞や助動詞がある場合でも、数詞の内部であることから区別します。

## 単位語

| 単位語 | 値 |
|---|---:|
| `8241` | 16⁰ |
| `8242` | 16¹ |
| `8243` | 16² |
| `8245` | 16³ |
| `82541` | 16⁴ |
| `82542` | 16⁸ |
| `82543` | 16¹² |
| `82545` | 16¹⁶ |

16²⁰以降は `8254` と全単射4進表記を使って規則的に作ります。

数字列形式 `14...` の末尾には `8241` を置き、最後の数字が16⁰の位であることを示します。
