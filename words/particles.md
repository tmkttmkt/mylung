# 助詞

助詞の意味上の分類と文法規則は、[文法の助詞](../grammar/particles.md) を参照してください。

助詞はすべて子音字と母音字からなる一音節の独立語とします。名詞との間には単語区切り `0` を置きます。

| 分類 | 語形 | 文字との関係 |
|---|---|---|
| 主体 | `81` | 動作・過程と、その起こり手 |
| 対象 | `63` | 具体化された第三の対象 |
| 到達・存在 | `72` | 特定の点・相手への結び付き |
| 場所・手段 | `93` | 出来事を成立させる外的な状況・内容 |
| 起点 | `D1` | 原因・駆動源・出発側 |
| 随伴 | `B2` | 別の参加者との対等な関係 |
| 所属 | `A5` | 後続する名詞への所有・帰属関係 |

同じ文字が品詞標識になる場合でも、位置によって区別できます。

```text
意味核6     → `6` は名詞標識
名詞0 63   → `63` は対象助詞
```

所属助詞は `所有者0 A5 被所有名詞` の順で使い、後ろの名詞を省略できません。

同定動詞では同定先に `72` を使います。`B2` を「同一の個体」という意味に拡張する案は保留します。
