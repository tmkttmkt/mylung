# 名詞

実際の語形は未定です。本文中の日本語名は説明用の仮称です。

## 最初期の基本名詞

### 生き物

生命を持つ存在を表します。生命の定義と、植物などを含む範囲は未決定です。

```text
D185E56
```

`D185E5`（生命核）に名詞標識`6`を付けた語です。

### 人間

`話す` と `生き物` から作る複合語です。

```text
D1F2D185E56
```

```text
D1F2 + D185E5 + `6`
言語活動核 + 生命核 + 名詞標識
```

ここでの `話す` は単に音声を出すことではなく、言語体系によって意味を構成し、やり取りすることを示します。詳しくは [動詞：話す](verbs.md#話す) を参照してください。

この語は、種としての人類に限定せず、「言語を使用する生き物」すべてを含む概念です。仮に人類以外の生物が十分な言語を使用することが確認されれば、その生物もこの語に含まれます。

一方、この言語の現在の設計思想では、現実にこの条件を満たす生物は人間だけだと捉えます。他の生物に単語や簡易な文法に相当する伝達体系があっても、その大部分が信号の羅列に留まり、生産的に意味を構成する言語には達していないと考えます。

ここでの区別は生物学上の種分類ではなく、この人工言語が採用する概念上の分類です。`話す` と認める条件は [動詞：話す](verbs.md#話す) を参照してください。

### 機械

```text
C1D256
```

`C1D25`（機械核）に名詞標識`6`を付けた語です。単純な道具から複雑な装置までを含む機械一般を表します。

情報処理機械はこの語とは別に、情報処理を表す核を前置した複合語として作る予定です。

### 四季

| 名詞 | 語形 | 意味核 |
|---|---|---|
| 季節 | `C3B56` | `C3B5` |
| 春 | `1C3B56` | `1C3B5` |
| 夏 | `2C3B56` | `2C3B5` |
| 秋 | `3C3B56` | `3C3B5` |
| 冬 | `543B56` | `543B5` |

季節そのものを抽象的に扱う場合は意味核を使い、具体的な季節として扱う場合は名詞標識 `6` を付けます。形容詞形はそれぞれ `C3B5A`、`1C3B5A`、`2C3B5A`、`3C3B5A`、`543B5A` です。
