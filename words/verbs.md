# 動詞

一部の基本動詞には語形が決まっています。未決定の動詞については、本文中の日本語名を説明用の仮称として使います。

## 最初期の基本動詞

### 存在する

人、動物、物などを区別せず、対象が存在することを表します。「いる」と「ある」に相当する動詞は分けません。

```text
E1C58
```

`E1C5`（存在核）に動詞標識`8`を付けた語です。

```text
存在する 対象
```

```text
存在する 1
```

「私は存在する」

場所を加える場合は、場所を示す助詞を使用します。

```text
存在する 1 場所・場所助詞
```

「私はその場所にいる」

### 同定する

二つの対象が同一であること、または対象がある分類に属することを表します。「AはBである」に相当します。

```text
B1B28
```

`B1B2`（同定核）に動詞標識`8`を付けた語です。

```text
同定する 被同定対象 同定先0 72
```

```text
同定する 1 人0 72
```

「私は人である」

同定先には `72` を付けます。`72` は、被同定対象が結び付けられる分類・性質・個体を示します。

```text
B1B28010810D1F2D185E56072
```

「私は人間である」

同定動詞は、「主体が対象をある分類へ同定する」という他動詞としても使用できます。この場合、判断する主体には `81`、同定される対象には `63`、同定先には `72` を付けます。

```text
B1B28010810D1F2D185E560630C1D256072
```

「私は人間を機械だと同定する」

標準VSOで曖昧さがなければ主体と対象の助詞は省略できますが、同定先の `72` は省略できません。

同定動詞は、存在や場所を表しません。

```text
存在する 1 場所   私はその場所にいる
同定する 1 人     私は人である
```

性質語は同定動詞の補語に置き、性質語自体を述語にはしません。詳しくは [性質語](properties.md) を参照してください。

### 話す

言語体系を用いて、意味を構成し、他者とやり取りすることを表します。単に声や信号を出すことよりも強く、言語を使用する行為・能力を指します。

```text
D1F28
```

`D1F2`（言語活動核）に動詞標識`8`を付けた語です。

音声に限定しません。手話など、体系的な言語による意思疎通も含みます。文字による言語活動をどこまで含めるかは未決定です。

次の行為は、原則として `話す` だけでは表しません。

- 意味を持たない音を出す
- 動物が鳴く
- 単純な合図を送る
- 表情や反射だけで状態を示す

これらが規則と意味を備えた言語体系として用いられる場合は、`話す` に含められます。

`話す` は、[人間](nouns.md#人間)を作る複合語の構成要素として使用します。

```text
話す + 生き物 → 人間
```

この言語における「言語体系」は、少なくとも次の性質を持つものとします。

- 意味を持つ単位がある
- 単位同士の関係を示す文法がある
- 単語の羅列を超え、組み合わせによって全体の意味が構成される
- 覚えた表現の反復だけでなく、新しい内容を生産できる

有限の合図、鳴き声、単語に近い信号、限定された順序規則だけでは `話す` に含めません。簡易な文法らしい構造があっても、表現の大部分が信号の羅列に留まる場合は同様です。

#### `言う`との区別

`話す` は言語活動や言語能力に焦点を置き、`言う` は特定の内容を一回の発話として表出することに焦点を置きます。

```text
話す 1          私は言語を使って話す
言う 1 内容     私はその内容を言う
```

`言う` は独立した動詞 `E1F18` として、`話す` と区別します。

### 言う

特定の内容を、一回の言語表現として外へ出すことを表します。

```text
E1F18
```

`E1F1`（発言核）に動詞標識 `8` を付けた語です。継続的な言語活動や会話ではなく、個々の発言内容に焦点を置きます。

```text
言う 1 内容
```

「私はその内容を言う」

### 見る

対象を視覚によって知覚することを表します。意図的に目を向けたかどうかは指定しません。

```text
E1B38
```

`E1B3`（視覚核）に動詞標識 `8` を付けた語です。「注視する」「眺める」などの意図的な視覚動作は、必要に応じて別の動詞として作ります。

```text
見る 1 機械
```

「私は機械を見る／機械が見える」

## 未決定事項

- 存在構文を使って所有を表すか
- 同定動詞を名前、所属、材料などにも使用するか
- `B2` を個体同士の同一性に使用するか

## `する`を作らない方針

日本語の「する」のように、任意の行為名詞を動詞化したり、文脈上の行為を代用したりする汎用的な軽動詞は作りません。

```text
勉強する → 学ぶ
仕事する → 働く
物を作る → 作る
移動する → 動く、行く、来る
```

名詞から新しい動詞を作る必要がある場合は、`する`を付けるのではなく、意味核の品詞標識を動詞標識へ付け替えます。詳しくは [意味核と品詞標識](../grammar/morphology.md#意味核と品詞標識) を参照してください。

文脈上の動詞を代用する「そうする」に相当する表現は、動詞の反復、省略、または後に決める代用表現で処理します。

## 決めたい動詞一覧

実際の語形を割り当てる前に、意味の範囲、必要な引数、似た動詞との区別を決めます。

### 決定済み

- [x] 存在する
- [x] 同定する
- [x] 話す
- [x] 言う
- [x] 見る

### 最優先

- [ ] なる：状態や分類の変化
- [ ] 作る：行為の結果として何かを生じさせる
- [ ] 持つ：所有を独立動詞で表すか、存在構文から表すか
- [ ] 行く：話者または基準点から離れる移動
- [ ] 来る：話者または基準点へ近づく移動
- [ ] 聞く：聴覚による知覚
- [ ] 知る：情報を知識として持つ
- [ ] 思う：判断、意見、心的内容を持つ
- [ ] 与える：対象を他者へ移す

### 基本動作

- [ ] 取る：対象を自分側へ移す
- [ ] 置く：対象を場所に位置させる
- [ ] 使う：対象を手段として行為する
- [ ] 動く：位置または状態が変化する
- [ ] 止まる：動きや進行を終了する
- [ ] 入る：領域の外から内へ移動する
- [ ] 出る：領域の内から外へ移動する
- [ ] 開く：閉じた状態を開いた状態へ変える
- [ ] 閉じる：開いた状態を閉じた状態へ変える

### 心理・認識

- [ ] 分かる：内容を理解する
- [ ] 覚える：情報を記憶に入れる、または保持する
- [ ] 忘れる：情報を想起できなくなる
- [ ] 感じる：感覚または感情を経験する
- [ ] 好む：対象を肯定的に評価する

### 会話

- [ ] 尋ねる：相手に情報を求める
- [ ] 答える：問いに対して情報を返す
- [ ] 呼ぶ：名前で指し示す、または相手の注意を引く
- [ ] 書く：言語を記録する
- [ ] 読む：記録された言語を理解する

### 生命・日常

- [ ] 生きる
- [ ] 死ぬ
- [ ] 食べる
- [ ] 飲む
- [ ] 眠る
- [ ] 起きる

### 関係

- [ ] 属する：集団や分類への所属
- [ ] 含む：全体が部分を内部に持つ
- [ ] 必要とする：対象を成立条件とする
- [ ] 助ける：他者の行為や状態改善を支援する

## 特に必要な区別

- `する` は作らず、`作る`などの具体動詞を使う
- `存在する` と `持つ` は分ける
- `知る` と `分かる` は分ける
- `見る` と「意図的に目を向ける」は分ける
- `聞く` と `尋ねる` は分ける
- `行く` と `来る` は分ける
- `話す` と `言う` は分ける
- `欲する` は動詞にせず、願望助動詞にする
- 性質語は状態動詞にせず、同定動詞の補語にする
