# 機能語

文法的な働きを持つ短い語を分類します。

## 分類

- 助詞
- 代名詞・指示語
- 疑問語
- 接続語
- 文末語
- 数量・限定語

## 助動詞

助動詞の語形は未定です。次の日本語名は、文法を検討するための仮称です。

| 分類 | 仮称 |
|---|---|
| 時制 | `現況`、`過去`、`未来` |
| 相 | `進行`、`完了` |
| 極性 | `否定` |
| 法 | `可能`、`推量`、`願望` |
| 文の用途 | `疑問`、`命令`、`依頼` |
| 情報源・認識態度 | `直接確認`、`伝聞`、`推論`、`不確定`、`断定`、`想定` |

禁止は専用語を作らず、`否定` と `命令` の組み合わせで表します。

意味、用法、配列順については [文の種類と助動詞](../grammar/sentence-types.md) を参照してください。
