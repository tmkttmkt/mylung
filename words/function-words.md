# 機能語

文法的な働きを持つ短い語を分類します。

## 分類

- 助詞
- 代名詞・指示語
- 疑問語
- 接続語
- 文末語
- 数量・限定語

## 助動詞

現在、一部の助動詞の語形が確定しています。未確定のものは日本語名を仮称として示します。

| 分類 | 語形・仮称 |
|---|---|
| 時制 | `現況`、`過去`、`未来` |
| 相 | `進行`、`完了` |
| 極性 | `E3` 否定 |
| 法 | `D3` 可能、`E2` 願望、`D5` 意思、`推量` |
| 文の用途 | `F3` 疑問、`D2` 命令、`F2` 依頼 |
| 情報源・認識態度 | `直接確認`、`伝聞`、`推論`、`不確定`、`断定`、`想定` |

禁止は専用語を作らず、`E3` 否定と `D2` 命令の組み合わせで表します。

確定した助動詞の意味、対応する概念核、用法は [助動詞](auxiliaries.md) を参照してください。配列順と文法上の作用域は [文の種類と助動詞](../grammar/sentence-types.md) を参照してください。
