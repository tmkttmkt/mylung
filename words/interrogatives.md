# 疑問語

## 基本形（暫定）

- `F3`：疑問助動詞。命題を質問として提示する文の用途を表す。語形・機能とも既存の確定仕様。
- `F31`：疑問対象・未知の値を示す疑問代名詞。単独では「何・どれ」、文脈によって「誰」などを表す。今回の追加仕様は暫定。

両者は役割が異なります。`F31` を使った通常の疑問文でも、述語に `F3` を付けます。ただし「何？」のように疑問語だけを発する省略形は許容します。

## 概念核との結合

意味核または複合核を `X` とすると、原則は **`X + F31`（基本後置）** です。一語として連結し、間に単語区切り `0` は置きません。

```text
F31         何・どれ（限定のない疑問対象）
B85F31     いつ・どの時間か
825F31     いくつ・どの数量か
D35F31     何度・どの温度か
C35F31     どの範囲か
```

`F31` は内容語の品詞標識ではありません。`X + F31` は既存の一般的な「修飾核＋中心核＋品詞標識」の複合語と区別する、専用の疑問語形成です。直接結合する `X` は意味核・複合核とし、助詞や既に品詞標識を付けた語形には直接結合しません。生成できるすべての疑問語を `lexicon.tsv` に列挙する必要はなく、複合語ツリーへ品詞派生や疑問派生の枝は出しません。

意味核による限定は質問対象の意味領域を指定するもので、例えば時間核 `B85` は時点・区間などを広く含みます。どの値を問うかの細部は文脈や追加の限定によって定まります。

## 格助詞との組み合わせ

助詞は独立語です。疑問語とは直接連結せず、正式表記では `0` で区切ります。

```text
F31081       誰が・何が
F31063       誰を・何を
F31072       誰に・何へ
F31093       どこで・何を手段として
F310D1       何を起点・原因として
F310B2       誰と・何と
B85F310D1    いつから・どの時間から
```

`F310D1` は「原因・起点の未知の値」を尋ねる表現ですが、理由と目的を必ず区別する専用疑問語ではありません。`F31093` も場所・道具・方法を文脈に応じて表し、様態全般を必ず表すとは限りません。専用の限定概念が必要になった場合は別途定義します。

## 例文

```text
E1B380F3010F31000
```

「私は何を見るか。」: 見る `E1B38`、疑問 `F3`、私 `1`、未知の目的語 `F31`。

```text
D1F280F30F31081000
```

「誰が話すか。」: 話す `D1F28`、疑問 `F3`、未知の主体 `F31`、主体助詞 `81`。

## 保留事項

- 従属疑問節など、文全体の質問ではない位置での `F3` の要否
- 「なぜ」と「何のために」、「どうやって」と「どのような状態で」の意味の細分化
- 種類選択、範囲限定、複数の疑問対象など複雑な疑問文の詳細構文

基本後置の疑問語形成と、格助詞を別語として扱う原則は、これらの未決定事項とは独立して運用します。
