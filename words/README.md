# 単語

語彙は、すべての語を収録する台帳と、文法を支える機能語に分けて管理します。

単語を作る際の母音字・子音字の区別は、[文字と音](../README.md#文字と音) を参照してください。
各文字が分野ごとに持つ意味は、[文字の意味](../symbols.md) で管理します。

| ファイル | 内容 |
|---|---|
| [lexicon.tsv](lexicon.tsv) | 意味核、派生語、機能語、標識を収録する語彙台帳 |
| [function-words.md](function-words.md) | 助詞、代名詞、疑問語、接続語など |
| [roots.md](roots.md) | 語根と派生関係 |
| [pronouns.md](pronouns.md) | 代名詞・指示語 |
| [verbs.md](verbs.md) | 動詞 |
| [nouns.md](nouns.md) | 名詞 |
| [properties.md](properties.md) | 性質語 |
| [particles.md](particles.md) | 助詞 |
| [auxiliaries.md](auxiliaries.md) | 助動詞 |
| [interrogatives.md](interrogatives.md) | 疑問語 |
| [conjunctions.md](conjunctions.md) | 接続語 |
| [numerals.md](numerals.md) | 数字の読みと数詞・単位語 |
| [time.md](time.md) | 時間、秒、分、時、日、週、月、年 |

`lexicon.tsv` の `category` 列で種類を区別します。

- 意味核だけを見る：`category` を `核` で絞る
- 意味核と複合核を見る：`category` を `核` と `複合核` で絞る
- 派生した内容語を見る：`派生語` で絞る
- 代名詞・助詞を見る：`機能語` で絞る
- 品詞標識を見る：`標識` で絞る
- 数詞と単位語を見る：`数詞` で絞る

これにより、すべてを一つの台帳に記録しながら、核だけの一覧も取り出せます。詳しい説明は各専用ファイルにも残します。

## 品詞標識

| 文字 | 意味 | 用法 |
|---|---|---|
| `6` | 具体・対象・事例 | 一般的・具体的な名詞を作る |
| `7` | 固有・個別 | 固有名詞を作る標識として予約 |
| `8` | 動作・変化・過程 | 動詞を作る |
| `9` | 内容・出来事 | 節を名詞化する標識として予約 |
| `A` | 性質・形容 | 形容詞を作る |

例えば、生命核 `D185E5` から次の語を作れます。

```text
D185E56 → 生き物
D185E58 → 生きる
D185E5A → 生きている、生命のある
```

語彙が増えた段階で、自然、身体、社会などの意味分野別ファイルを追加します。
