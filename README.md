# mylung

`1`〜`9` と `A`〜`F` の15文字だけで表記する人工言語です。`0` は境界と句読点に使い、連続する数によって働きを区別します。

```text
31020A5070C14
```

この言語では、各文字を品詞番号や命令コードとして扱いません。`1`〜`F` はアルファベットのように抽象化された文字であり、その組み合わせが単語になります。

## 方針

- 自然言語に近い使い心地を目指す
- 単語の長さは固定しない
- 語順や助詞、接辞によって文法を表す
- 文脈から分かる主語や目的語は省略できる
- 規則性を持たせつつ、多義性や慣用表現も許容する
- 機械的な解析のしやすさを最優先にはしない
- 各文字の具体的な発音は現時点では定義しない
- `1`、`2`、`3`、`5`を母音字、`4`をゼロ初声字、`6`〜`F`を子音字として扱う

文法は、基本語順をVSO（動詞・主語・目的語）とし、省略可能な助詞によって語順を変更できる仕組みを検討しています。語彙・助詞・活用・詳しい構文規則はまだ未定です。

## 文字と音

15文字を、4個の母音字、1個のゼロ初声字、10個の子音字に分けます。

```text
母音字：     1 2 3 5
ゼロ初声字： 4
子音字：     6 7 8 9 A B C D E F
単語区切り： 0
読点：       00
句点：       000
```

## 境界と句読点

`0` の連続数を最長一致で読みます。

| 表記 | 働き | 日本語表記での対応 |
|---|---|---|
| `0` | 単語区切り | 空白 |
| `00` | 読点 | `、` |
| `000` | 句点 | `。` |

読点と句点は、それ自体に単語区切りを含むため、前後に追加の `0` を置きません。

```text
語0語000                 → 語 語。
語0語00語0語000          → 語 語、語 語。
```

`0` を4個以上連続させる表記は使用しません。

正式表記では単語間の `0` を省略しません。ただし非正式な表記では、動詞・形容詞に続く助動詞の前と、助動詞同士の間に限って `0` を省略できます。その他の単語境界では省略できません。

`1`〜`F` は抽象化された文字です。各文字の具体的な発音はまだ定義しませんが、単語を作る際には母音と子音の区別を使用します。

`4` は発音せず、語中で母音から始まる新しい音節を示します。語中の `4` は必ず二つの母音字に挟まれた `V4V` の形で使用します。

```text
15    同一音節内の母音連続
145   別音節に分かれる母音連続（1.45）
14142 3個の母音からなる3音節（1.41.42）
```

語頭のゼロ初声字は省略します。したがって、通常は `41` ではなく `1` と書きます。

次の形は禁止します。

```text
4     後続する母音がない
46    子音字の直前にある
44    ゼロ初声字が連続している
614   語末にある
1641  子音字の直後にある
```

`1641` のような `C4V` を禁止するため、`4` は一般的な空位置ではなく、母音間の音節境界だけを表します。

### 子音連続（暫定）

- 子音は最大2個まで連続できる
- 語頭と語中の2子音連続を許可する
- 語末には1子音だけ置ける
- 語末の2子音連続は許可しない
- 具体的に許可する子音の組み合わせは、各文字の音価を決めた後に制限する

```text
6A1   許可：CCV
16A2  許可：VCCV
16    許可：VC
16A   禁止：VCCで終わる
```

### 母音連続（暫定）

`4`を挟まない母音連続は、同じ音節に属します。同じ母音字の反復は長母音として扱います。

```text
15   同一音節内の母音連続
11   長母音
145  別音節の母音連続
```

### 単語の長さ（暫定）

- 機能語は主に1〜2音節とする
- 一般語は主に1〜3音節とする
- 厳密な上限は設けない
- 4音節以上の語は、主に派生語や複合語として作る

具体的な音価、アクセントなどは、基本単語を試作しながら決定します。
